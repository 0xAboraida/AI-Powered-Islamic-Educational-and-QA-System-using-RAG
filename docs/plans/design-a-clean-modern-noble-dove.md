# تحسينات صفحة قاعدة المعرفة (Knowledge Base) — Zad-AI

## Context
المستخدم وافق على تنفيذ كل التحسينات المقترحة لصفحة قاعدة المعرفة عشان تتحوّل من "عرض جميل" لأداة فعلية مربوطة بالـ AI، بجودة تليق بمشروع تخرّج. التعديلات كلها داخل مكوّنات موجودة بالفعل — مفيش تغيير في الهوية البصرية.

## الملفات المتأثّرة
- `src/components/knowledge/KnowledgeBase.tsx` — معظم المنطق (بحث، فلاتر، عدّاد، فتح/طيّ الكل، skeleton، تحميل تدريجي، a11y، تظليل).
- `src/components/knowledge/data.ts` — إضافة helper لحساب الإجماليات (اختياري).
- `src/App.tsx` — تمرير callback من قاعدة المعرفة لفتح المحادثة بسؤال مبدئي (زر "اسأل زاد").
- `src/components/chat/ChatScreen.tsx` — قبول سؤال مبدئي اختياري (`initialQuestion`) وإرساله تلقائيًا.

## التعديلات

### 1. تظليل نتيجة البحث (highlight)
دالة `<Highlight text query />` صغيرة داخل `KnowledgeBase.tsx` تقسّم النص وتغلّف المطابقة بـ `<mark>` بلون `bg-accent/20 text-primary`. تُستخدم في اسم الكتاب واسم المؤلف.

### 2. عدّاد نتائج + مسح الفلاتر
حساب إجمالي الكتب/المجالات الظاهرة من `visible`. سطر أعلى القائمة: «تم العثور على N كتابًا في M مجالات» + زر «مسح الكل» يظهر فقط عند وجود بحث أو فلتر ≠ الكل.

### 3. فتح/طيّ الكل
حالة `expandAll: boolean` في `KnowledgeBase`، تُمرّر لـ `DomainAccordion` عبر prop `forceOpen` (موجود أصلًا) مدموجة مع البحث. زرّان صغيران «فتح الكل / طيّ الكل».

### 4. حفظ الحالة (localStorage)
حفظ `query` و`filter` في `localStorage` (مفتاح `zad-kb`) واستعادتها عند التحميل عبر `useEffect`. (URL sync اختياري — نكتفي بـ localStorage لتفادي إضافة راوتر.)

### 5. زر «اسأل زاد عن هذا الكتاب»
`BookCard` يستقبل `onAsk(book)`. عند الضغط يستدعي callback من `App` يفتح `ChatScreen` مع `initialQuestion` = «حدّثني عن كتاب "X" للمؤلف Y وما موضوعاته». `ChatScreen` يرسل السؤال تلقائيًا عند التحميل عبر `useEffect`.

### 6. شارة "مصدر معتمد"
شارة صغيرة `✓ مصدر معتمد` على بطاقة الكتاب بلون هادئ.

### 7. Skeleton loading
حالة `loading` (محاكاة ~500ms عبر `setTimeout` في `useEffect`) تعرض بطاقات هيكلية `animate-pulse`. يمهّد لربط API لاحقًا.

### 8. تحميل تدريجي داخل التصنيف
لو عدد كتب تصنيف > 24، عرض دفعة أولى + زر «تحميل المزيد» يزيد الحدّ. حالة محلية داخل عرض التصنيف.

### 9. إحصائية الـ Hero
حساب إجمالي الكتب والمجالات من `domains` وعرضها في الـ Hero: «+N كتاب · M مجال».

### 10. إتاحة الكيبورد (a11y)
أزرار الـ Accordion أصلًا `<button>` (تدعم Enter/Space). إضافة `aria-controls`/`id` للربط، و`aria-expanded` (موجود). ضمان `focus-visible` ring واضح.

### 11. prefers-reduced-motion
قاعدة CSS في `src/index.css`: `@media (prefers-reduced-motion: reduce)` تعطّل الـ transitions/animations للحركة.

## التحقق
- `npx tsc --noEmit` نظيف (باستثناء ملفات `imports/` للقراءة فقط).
- فحص يدوي في المعاينة: البحث يظلّل، العدّاد يتحدّث، فتح/طيّ الكل يشتغل، زر "اسأل زاد" ينقل للمحادثة بسؤال جاهز، skeleton يظهر عند التحميل، الحالة تُحفظ بعد التحديث، والتصميم Responsive.
