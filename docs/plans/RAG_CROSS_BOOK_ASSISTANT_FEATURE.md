# ميزة المساعد التراثي المقارن ونظام الـ RAG المفلتر (Cross-Book RAG Assistant)

## 📌 نبذة عامة عن الميزة
تطوير "مساعد زاد الذكي" في قارئ التراث (`TurathReader`) لينتقل من مجرد الإجابة من سياق الصفحة المعروضة وذاكرة النموذج العامة، إلى **محقّق وباحث تراثي مقارن** مدعوم بتقنية الـ **RAG (Retrieval-Augmented Generation)** مع إمكانية **الفلترة الدقيقة على مستوى كتاب محدد أو كامل المكتبة**.

---

## 🎯 الهدف وحالات الاستخدام الأساسية (Use Cases)

1. **الشرح المباشر السريع (Quick In-Page Mode):**
   - الشرح من سياق الصفحة الحالية والذاكرة المباشرة بدون تكلفة RAG إضافية (الوضع الحالي).
2. **البحث في كامل الكتاب الحالي (In-Book RAG):**
   - البحث الدلالي في كافة مجلدات وصفحات الكتاب الحالي الذي يقرأه المستخدم.
   - *مثال:* "أين تحدث الإمام الشافعي في هذا الكتاب عن خبر الواحد وشروطه؟"
3. **المقارنة والشرح من كتاب تراثي آخر محدد (Cross-Book Filtered RAG):**
   - استفسار القارئ عن عبارة أو مسألة في الصفحة الحالية، ولكن بطلب شرحها ومقارنتها من كتاب آخر محدد مفهرس في الـ RAG.
   - *مثال:* "المؤلف ذكر هنا مسألة بيع الغرر، اشرح لي هذه المسألة من كتاب [المغني لابن قدامة]".
   - يقوم النظام بتوجيه الاستعلام مع فلترة خاصة (`filter: { book_title: "المغني" }`).
4. **البحث العام في كافة كتب التراث (Global Library RAG):**
   - استعراض الأقوال وتخريج المسائل ومقارنة المذاهب عبر كل الكتب المفهرسة في قاعدة المتجهات.

## 🎨 تصميم تجربة المستخدم والواجهة (UI / UX Architecture)

### 1. شريط تحديد المرجع والنطاق (Scope & Reference Picker)
يوضع زر أو شارة أنيقة مدمجة إما فوق شريط الإدخال أو بداخله بجوار حقل النص:
- **الأوضاع المتاحة:**
  - `⚡ الصفحة الحالية` (الافتراضي - سريع وخفيف).
  - `📖 هذا الكتاب كاملاً` (يبحث في كامل أجزاء الكتاب الحالي).
  - `🔍 كتاب محدد آخر...` (يفتح قائمة سريعة منسدلة بالكتب المتاحة في الـ RAG للفلترة، مثل: المغني، المجموع، بداية المجتهد، فتح الباري...).
  - `🌐 المكتبة الشاملة` (بحث حر في كل كتب الـ RAG).

### 2. التوجيه الذكي التلقائي (NLP Auto-Routing)
- إذا كتب المستخدم في سؤاله نصاً يحتوي على اسم كتاب (مثلاً: *"وضح لي كلام الشافعي هنا من المغني"*):
  - يقوم النموذج أو الواجهة باستخراج اسم الكتاب المستهدف تلقائياً وتفعيل الفلتر عليه دون الحاجة لاختياره يدوياً.

### 3. ربط النص المحدد بالسياق (Context Anchoring)
- عند تظليل/تحديد نص في الصفحة، تظهر خيارات القائمة المنبثقة:
  - `[ اشرح هذا النص ]` ⬅ شرح من الصفحة.
  - `[ قارن في كتاب آخر... ]` ⬅ اختيار الكتاب المستهدف، ليُرسل النص المحدد كمرجع للمقارنة.

### 4. بطاقات الاستشهاد والأمانة العلمية (Source Badges & Deep Links)
عند ورود الإجابة من الـ RAG:
- يظهر أسفل الرد كارت مميز:
  - 🏷️ **المصدر:** *كتاب المغني - لابن قدامة (باب البيوع).*
  - 📄 **الموضع:** *المجلد 4، صفحة 182.*
  - 🔗 **زر تفاعلي:** `[ انتقال للصفحة في القارئ ]` (يقفز تلقائياً لصفحة المرجع إن كانت متوفرة في المنصة).
  - زر طي/عرض: `[ عرض النص التراثي المقتبس الأصلي ]`.

## 🛠️ مواصفات الـ API ومخطط البيانات (Data Schema)

### 1. طلب الـ Frontend للـ API (`POST /api/v1/reading-assistant/explain` أو نقطة RAG مخصصة):

```typescript
interface ReadingAssistantRagRequest {
  user_message: string;             // سؤال المستخدم
  selected_text?: string;           // النص المقتبس المحدد من الصفحة (إن وجد)
  current_book: {
    title: string;
    author: string;
    volume?: number;
    page: number;
    chapter?: string;
  };
  rag_mode: 'current_page' | 'current_book' | 'specific_book' | 'global_library';
  target_book_filter?: string;      // اسم الكتاب المستهدف للفلترة (مثلاً: "المغني")
  target_author_filter?: string;    // فلترة باحث/مؤلف معين (اختياري)
  history: Array<{
    role: 'user' | 'model';
    content: string;
  }>;
}
```

### 2. استجابة الـ API (`Response Payload`):

```typescript
interface ReadingAssistantRagResponse {
  reply: string;                    // الشرح وصياغة الجواب
  rag_applied: boolean;             // هل تم تفعيل RAG؟
  sources: Array<{
    book_title: string;
    author: string;
    volume?: number;
    page_number?: number;
    chapter?: string;
    snippet: string;                // الفقرة التراثية المقتبسة
    score?: number;                 // درجة المطابقة الدلالية
  }>;
}
```

## 🚀 خطة التنفيذ الموصى بها عند البدء (Execution Roadmap)

1. **المرحلة الأولى (واجهة المستخدم - Frontend UI):**
   - إضافة قائمة اختيار النطاق والكتاب المستهدف (Reference Selector) أعلى شريط إدخال المساعد.
   - تجهيز مكون بطاقة المصادر المقتبسة (`SourceBadge` / `CitationCard`) في رسائل الشات.
   - ربط النص المظلل بخيار "قارن في كتاب آخر".

2. **المرحلة الثانية (الربط البرمجي ومحرك الـ Backend):**
   - توفير قائمة بالكتب المفهرسة حالياً في الـ Vector DB لاختيارها في القائمة المنسدلة.
   - إرسال `target_book_filter` إلى نقطة الـ RAG مع المعاملات.
   - فلترة المتجهات على مستوى الميتاداتا (`metadata.book_title == target_book_filter`).

3. **المرحلة الثالثة (التجربة والتحسين):**
   - اختبار جودة استخراج الأجوبة التراثية والتحقق من دقة أرقام الصفحات والمراجع.
   - إضافة روابط القفز المباشر للصفحة للمراجع التي يمتلك القارئ بياناتها.
